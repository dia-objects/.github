# Dia - Diagrams You Draw Yourself

Dia is a diagram editor for flowcharts and simple structures you already understand. You place objects and connect them. Layout is your choice. The program does not discover hosts.

---

## Product Snapshot

A canvas starts empty. You add a box, type a label, and draw a line to the next box. Layers can hold a background you do not want to edit by accident. None of that imports a live network. If you load a file, it should be a diagram you made or were given to edit.

Export a PNG or similar when a page needs a picture. Save the Dia document under a name you will find. A screenshot without the document is hard to revise. Do not put passwords on the canvas unless you accept that the file is as private as those passwords.

## Highlights

- An empty canvas you fill
- Objects you name
- Lines you connect
- Layers for a part you want to lock
- Export of a picture
- The Dia file kept for the next edit

---

## Live Production

Use it for a process you run or a sketch of software you are writing. Five objects are enough to learn save and export. Share the picture, and keep the document. If the drawing describes a private system, store it with your other private files.

Dia will not validate that the drawing matches real equipment. It will not scan an address range. A shape library you add should be one you may use.

---

## Picture Versus Document

Export is for showing the drawing. The Dia file is for changing it. Keep both. If you only have the picture, you will redraw the boxes the next time a label changes.

---

## Setup Path

Prerequisites: A folder for the document, and a structure you can explain.

1. Install Dia and create a new diagram in that folder.
2. Add a few named objects and connect them.
3. Save the document.
4. Export a picture and open it outside Dia.
5. Change the next label in the document, not in the picture.

## Who Benefits

Dia fits a flowchart or a small architecture sketch you are allowed to keep. It does not fit network discovery, a dump of systems you were not given, or a password written on the page.

---

## Fixes

A line will not connect: the objects are not the ones you selected. Click them again. The export clips a label: widen the object in Dia and export again. The file will not reopen: you saved only the picture. Use the Dia document next time.
